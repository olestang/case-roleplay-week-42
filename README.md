# Kindergarten Conversations

Static roleplay site for VG1 English (Health and Childhood Development), Lukas VGS.

## GitHub Pages

Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository settings. No build step, server, framework or external dependency is required.

The site uses only HTML, CSS, JavaScript and `localStorage`.

## Student flow

1. Choose 3 or 4 people.
2. Everyone chooses the same case.
3. Everyone chooses a different role.
4. Each student chooses their own English level. Levels contain the same story information; only the language complexity changes.
5. Read the private role story.
6. Hide/put away the story and roleplay the conversation. One role is marked as the conversation starter.

## Included cases

- I Don’t Want to Play With You (3 or 4)
- The Missing Teddy Bear (3 or 4)
- The Birthday Cake Problem (3 or 4)
- The Child Who Does Not Want to Go Outside (3 or 4)
- The Parent Who Wants More Learning (3 or 4)
- The Rough Play Complaint (4 only)
- The Photo That Should Not Have Been Shared (3 or 4)
